Fixture: /tmp/shuffle-demo-evidence (tools/demo-library.py), with one
cached preview added and one track staged from outside the music root.

session bus (tools/headless-run.py); its answer is the dump-state
document a machine client reads. The CLI is a subprocess running
python3 -m ipod_gui.cli library against the same HOME.

      PATH=$REPO/tests/bin:$PATH \
